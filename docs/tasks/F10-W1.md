# F10-W1: App — "Ver projeto" page (read-only, for showing the family, the engineer, or the client)

**Goal:** the user opens `/ver?id=<project>` (or clicks "Ver como apresentação" (View as presentation)) and gets a clean page with no editing tools. It has the 3D view in presentation mode (sun, light, and an indoor walkthrough), the floor plan, the key numbers (area, cost, rooms), the saved photos, and a button to download the PDF. It works well on mobile. No login, on the same local server; on the local network, it works through the IP.

- `apps/web/components/viewer/**` (new).
- `apps/web/components/editor/TopBar.tsx`, only for the "Ver como apresentação" item (opens `/ver?id=` in a new tab) and "Copiar link da rede local" (Copy local network link), if the IP can be discovered. In `next dev` the terminal shows "Network: http://192.168.x.x:3000"; on the client, use `window.location`. If that is not possible, leave only the local link.

## 1. Data
- Load the project through the existing API (`/api/projects/[id]`) or through the `StorageAdapter` used in the editor.
- Compute with the same hook/worker as the editor (`useEngine` or equivalent).
- If the editor store is needed by the scene components (`useEditor`), initialize it with `loadProject` in read mode: no editing action exposed and no autosave. Check that autosave fires only on `dirty`; if not, make sure the page does not save.

## 2. Layout (`components/viewer/ViewerPage.tsx`)
- **Desktop:** large 3D view on the left (`presentation` mode) and, on the right, a panel with:
  - project name, typology, built area, rooms (name and area), estimated cost (range), and construction system;
  - tabs "Planta" (Floor plan; SVG floor plan per level, from `lib/plan2d`), "Números" (Numbers; cost per stage), and "Sobre" (About; ART notice, where ART is the Anotação de Responsabilidade Técnica, the engineer's liability record);
  - buttons: "Baixar PDF" (Download PDF; the existing generator), "Salvar imagem" (Save image; the presentation image export), and "Abrir no editor" (Open in editor).
- **Mobile** (< 768 px): 3D view on top (60% of the height) and the panel below, scrollable. The indoor walkthrough on mobile is optional: without `PointerLock`, orbit only.
- **Sun controls** (existing panel): time and date. Hide the controls that only make sense for someone editing.
- Clean, attractive look, with a discreet ChaléCAD brand at the top and a footer "Feito com ChaléCAD · estimativa, não substitui projeto com ART" (Made with ChaléCAD · estimate, does not replace a project with ART).

## 3. Nonexistent project or error
- Friendly message and a link to the project list.
