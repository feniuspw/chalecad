# F10-W1: App — página "Ver projeto" (somente leitura, para mostrar a família, o engenheiro ou o cliente)

**Objetivo:** o usuário abre `/ver?id=<projeto>` (ou clica em "Ver como apresentação") e tem uma página limpa, sem ferramentas de edição. Tem o 3D no modo apresentação (sol, luz e passeio por dentro), a planta, os números principais (área, custo, cômodos), as fotos salvas e o botão de baixar o PDF. Funciona bem no celular. Sem login, no mesmo servidor local; na rede local, funciona pelo IP.

**Pode alterar:**
- `apps/web/app/ver/**` (nova rota).
- `apps/web/components/viewer/**` (novo).
- `apps/web/components/editor/TopBar.tsx`, só para o item "Ver como apresentação" (abre `/ver?id=` em nova aba) e "Copiar link da rede local", se der para descobrir o IP. Em `next dev` o terminal mostra "Network: http://192.168.x.x:3000"; no cliente, use `window.location`. Se não der, deixe só o link local.
- Testes junto.

**Não altere:** `packages/**`, `lib/store/**`, `package.json`, `components/editor/EditorShell.tsx`, `components/editor/NewProjectDialog.tsx`, `components/onboarding/**`, `components/projects/**`, `lib/project/presets/**` e `lib/project/templates.ts` (do F8-W2, em paralelo).
- `components/scene/**` só para leitura e reuso. Se precisar de uma prop nova num componente de cena (ex.: `readOnly`), pode acrescentar desde que seja opcional e não mude o comportamento atual.

## 1. Dados
- Carregue o projeto pela API existente (`/api/projects/[id]`) ou pelo `StorageAdapter` usado no editor.
- Calcule com o mesmo hook/worker do editor (`useEngine` ou equivalente).
- Se o store do editor for necessário para os componentes de cena (`useEditor`), inicialize-o com `loadProject` em modo leitura: nenhuma ação de edição exposta e sem autosave. Confira se o autosave dispara só com `dirty`; se não, garanta que a página não salva.

## 2. Layout (`components/viewer/ViewerPage.tsx`)
- **Desktop:** 3D grande à esquerda (modo `presentation`) e, à direita, um painel com:
  - nome do projeto, tipologia, área construída, cômodos (nome e área), custo estimado (faixa) e sistema construtivo;
  - abas Planta (SVG da planta por nível, de `lib/plan2d`), Números (custo por etapa) e Sobre (aviso de ART);
  - botões: Baixar PDF (o gerador existente), Salvar imagem (o export de imagem da apresentação) e Abrir no editor.
- **Celular** (< 768 px): 3D em cima (60% da altura) e painel embaixo, rolável. O passeio por dentro no celular é opcional: sem `PointerLock`, só órbita.
- **Controles do sol** (painel existente): hora e data. Esconda os controles que só fazem sentido para quem edita.
- Visual limpo e bonito, com a marca ChaléCAD discreta no topo e rodapé "Feito com ChaléCAD · estimativa, não substitui projeto com ART".

## 3. Projeto inexistente ou erro
- Mensagem amigável e link para a lista de projetos.

## Testes de aceite

- A página não chama `update`/`save`. Teste a inicialização em modo leitura, se for uma função pura; senão, explique como garantiu.
- `pnpm --filter @chalecad/web typecheck`, `lint`, `test` e `build` verdes (separados).
- No retorno: como verificar (inclusive no celular pela rede local) e o que ficou de fora.
