# F1-E2: Engine — quantity takeoff, cutting plan, and weight

**Goal:** from the `BuildingModel`, the `Piece[]`, the project, and the catalog, generate the `QuantityReport` (purchase list per stage, cutting plan, areas, steel index) and the `WeightReport`. Types in `packages/engine/src/schema/results.ts`.

**May change:** `packages/engine/src/quantities/**`, `packages/engine/src/weight/**`, `packages/engine/src/index.ts` (exports only), `packages/engine/test/quantities/**`, `packages/engine/test/weight/**`, `packages/engine/test/helpers/**` (may add new files).
**Do not change:** `src/schema/**`, `src/model/**`, `src/framing/**` (another agent is writing the framing in parallel), `packages/catalog/**`.

## API
```ts
export function cutPlan(pieces: { id: string; length: number }[], barLengths: number[], kerf: number): CutBar[];
export function computeQuantities(model: BuildingModel, pieces: Piece[], project: Project, catalog: Catalog): QuantityReport;
export function computeWeight(model: BuildingModel, pieces: Piece[], quantities: QuantityReport, project: Project, catalog: Catalog): WeightReport;
```
Use `getCatalog()` from `@chalecad/catalog` and `buildModel` (already done in `src/model`) in tests. Since `generatePieces` does not exist yet on your branch, create a simple synthetic generator in `test/helpers/pieces.ts` (e.g., studs every 0.6 m on each wall, tracks, a few rafters) only to test the flow; the fine-grained numbers will be validated at integration by the orchestrator. Constants always from `catalog.constants`; waste from `material.wastePct`. Nothing hard-coded.

## Rules
**Structure (stage `structure`)**
- Group pieces by `profileId`. Cutting plan: First-Fit Decreasing on bars of the longest available length (`profile.barLengths`), discounting `constants.sawKerf` per cut; then swap each bar whose used total fits in a shorter bar for the shortest one. A piece longer than the longest bar: split into segments (splice) and record a `note` on the line.
- One `QuantityLine` per profile × bar length: `itemId` = profileId, `priceItemId` = `profile.priceItemIds[i]`, `unit` = `barra 6 m`/`barra 3 m` (6 m bar / 3 m bar), `purchaseQty` = number of bars, `netQty` = Σ lengths (m), `netUnit 'm'`, `wastePct` = leftover/total purchased, `weightKg` = bars × length × massPerM (purchased weight, used for freight), `pieceIds`, `hostIds`.
- Straps (`Fita*`): sold by the roll (`barLengths[0]` = roll length): rolls = ceil(Σ length × 1.05 / roll).
- Fasteners: profile-to-profile screws (`screw_frame`) = (studs, king, jack, cripple, stud_corner) × `lsf.screwsPerStud` + blocking × 4 + headers × 8 + joists/rafters/collar ties × 4 + purlins × 2 × (length/rafterSpacing + 1); anchor bolts (`anchor_bolt`) = Σ bottom tracks of the ground level / `lsf.anchorSpacing` + 2 per wall; hold-downs (`hold_down`) = 2 per exterior wall + 2 per opening with width > `lsf.holdDownOpeningMin`.

**Closures (stages of the assembly layers)**
- For each `HostWall`: gross area = area of the `outline`; net area = gross − Σ valid openings. For each layer of the assembly (`catalog.assemblies`): face area = net (`ext`, `int`, `core`) or 2 × net (`both`); consumption = area × `consumptionPerM2` (in the material's baseUnit).
- Materials with `purchase.sheet` (boards): **layout (paginação)** per face: columns = ceil(L / sheet.width), rows = ceil(Hmax / sheet.height); count the boards whose rectangle intersects the outline and is not entirely inside an opening. `purchaseQty` = laid-out boards (no extra waste); `wastePct` = (purchased area − net)/net.
- Other materials: quantity = consumption × (1 + wastePct/100) / `purchase.size`, rounded up if `purchase.integer`.
- A-frame `isWall` roof planes receive the `int`/`core` layers of `system.assemblies.interior` on the area of the roof plane minus openings.
- Aggregate lines by the (itemId, stage) pair, summing quantities and merging `hostIds`.

**Roof (stage `roof`)**
- Roof panel (`project.roof.cladding`, material): per roof plane, number of panels = ceil(uLength / `roof.sandwichUsefulWidth`), each with vLength; `purchaseQty` in m² = panels × vLength × 1.0 (nominal width 1 m), with `note` "N telhas de X m" (N panels of X m).
- Ridge cap (`ridge_cap`, baseUnit m): netQty = ridge length (including rake), purchase per the material's `purchase`. Flashing (`flashing`): gable edges (sloped sides of the roof planes) / `roof.flashingLength`. Gutters (`gutter`) if `roof.gutters`: eave length / `roof.gutterLength`. Roof screws (`screw_roof`): area × `roof.screwsPerM2`. Skylights subtract area and generate a `skylight` line (m²).

**Mezzanine (stage `structure`)**
- `floor_osb18`: polygon area, laid-out boards (area / 2.88 with the material's waste, rounded up). Guardrail (`guardrail`, m): polygon edges that do not coincide (±5 cm) with walls, if `level.guardrail`.

**Openings (stage `finishing`)**
- `door_ext` (door in an exterior wall), `door_int` (interior) in un; `window_alu` m²; `sliding_door` m²; the glass of glazed gable ends comes from the `gable_glazed` assembly.

**Radier foundation (raft slab; stage `foundation`)**
- A = area of the `radier` slab; perimeter P. Concrete (`concrete_fck25`, m³) = A × thickness + P × `radier.edgeBeamWidth` × (edgeBeamDepth − thickness). Mesh (`mesh_q138`) = A × meshOverlapFactor / 6 m² per panel. Plastic sheeting (`lona_200`) = A × lonaOverlapFactor. Gravel (`gravel_1`) = A × gravelThickness. Form (`edge_form`, m) = P. Pipes: for each `utilities` sewer, length to the nearest radier edge + 1 m (`pvc_sewer_100`); water likewise (`pvc_water_25`).

**Floor (stage `floor`)**, ground level with `floor` ≠ 'none': area = w × d (axis to axis) minus interior wall area (length × thickness). Hardener (`floor_hardener`) = area × `constants.floor.hardenerKgPerM2`; sealer (`sealer`) = area × `constants.floor.sealerLPerM2`. Joint cutting (`joint_cut`, m) = lines every `radier.floorJointSpacing` in both directions.

**Stairs (stage `finishing`)**: `stair_tread` = treads; ship's ladder: `ladder` in m.

**Areas**: fill in `Areas` (footprint, built, roof = Σ roof planes, exteriorWallsNet, interiorWallsNet, openings, radier, mezzanine).
**Steel index**: `steelKg` = Σ(length × massPerM) of the pieces (net); `steelKgPerM2` = steelKg / builtArea.

**Weight (`computeWeight`)**: net self-weight (not the purchased weight): steel of the pieces + layers (area × massPerUnit) + roof panel + mezzanine OSB + concrete. `byStage`, `byElement` (per host: each wall, each roof plane, mezzanine, radier, stairs; pt-BR label, e.g., "Parede frontal" (Front wall), "Água A" (Roof plane A)), `superstructureKg` = total − foundation, `kgPerM2` = superstructureKg / builtArea, `totalKg`.

## Acceptance tests
- `cutPlan`: classic cases (e.g., [2.5, 2.5, 1, 4, 3] on 6 bars with kerf 0 → 3 bars; with bars [3, 6] it swaps the last one to 3 m when it fits); no cut longer than the bar; kerf accounted for.
- Board layout: 3 × 2.8 wall with no openings with a 1.2 × 2.4 board → 3 columns × 2 rows = 6 boards; with a window that contains one whole board, 1 fewer.
- 6.5 x 8.5 fixture with the synthetic generator: lines in the foundation, structure, closure, roof, floor, finishing stages; no negative/NaN quantity; every `priceItemId` exists in the `default-2026-11` price book; radier concrete checked by hand (document it).
- Roof panel: 2 roof planes of uLength 9.1 → ceil(9.1/0.98) = 10 panels per plane.
- `computeWeight`: total = Σ byStage (±0.1%); superstructure < total.
- `computeQuantities` + `computeWeight` of the fixture < 40 ms.
