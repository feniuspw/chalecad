**Pode alterar:** `apps/web/e2e/**`, `apps/web/playwright.config.ts`, `.github/workflows/ci.yml` (novo, opcional: install, typecheck, lint, test, build, e2e).
**Não altere:** código do app. Se um teste revelar bug, NÃO corrija: marque com `test.fixme` e descreva o bug no retorno (passo a passo, esperado × obtido).

## Configuração
- `webServer`: `pnpm --filter @chalecad/web dev --port 3110` (reuseExistingServer false), baseURL `http://localhost:3110`, Chromium, `CHALECAD_DB_PATH` apontando para um arquivo temporário em `apps/web/test-results/e2e.sqlite`. Viewport 1440 x 900.
- Em desenvolvimento o app expõe `window.__editor` (store Zustand) e `window.__sceneInfo`: use-os para asserts de estado quando o DOM não bastar (ex.: `await page.evaluate(() => window.__editor.getState().results?.pieces.length)`).

## Cenários
1. Landing carrega, CTA leva ao editor.
2. Primeiro acesso: assistente aparece; "Usar o chalé de exemplo" fecha e o painel mostra custo total em R$ e área 78,0 m².
3. Mudar a largura (NumberInput) de 6,5 para 7,5: área construída e custo mudam em < 1 s; desfazer (Ctrl+Z) volta ao valor anterior.
4. Clicar numa linha da aba Materiais define `highlight` no store com peças (critério "clicar numa linha destaca as peças no 3D").
5. Recarregar a página reabre o mesmo projeto com o mesmo custo total (critério "salvo e reaberto reproduz os mesmos resultados").
6. Exportar JSON (download) e reimportar pelo menu Abrir: mesmo custo.
7. Aviso de ART visível no editor; PDF gerado contém o aviso (abra o download e procure o texto com `pdf-parse` se estiver disponível; senão só confira o download e o nome do arquivo).
8. Modos Estrutura e Mapa de calor ativam sem erro de console.
9. `/projetos` lista o projeto salvo; "Novo projeto" abre o assistente.
10. Novo projeto A-frame pelo assistente calcula sem alertas de erro.
11. Nenhum erro de console (exceto 404 esperados de `/api/projects/<id>` quando o projeto só existe localmente) em todos os cenários.
