# F4-W9: End-to-end tests (Playwright) of the main flows

**Goal:** a Playwright suite that guarantees the spec's general acceptance criteria in the real app.

**May change:** `apps/web/e2e/**`, `apps/web/playwright.config.ts`, `.github/workflows/ci.yml` (new, optional: install, typecheck, lint, test, build, e2e).
**Do not change:** app code. If a test reveals a bug, do NOT fix it: mark it with `test.fixme` and describe the bug in the return (step by step, expected vs. actual).

## Configuration
- `webServer`: `pnpm --filter @chalecad/web dev --port 3110` (reuseExistingServer false), baseURL `http://localhost:3110`, Chromium, `CHALECAD_DB_PATH` pointing to a temporary file at `apps/web/test-results/e2e.sqlite`. Viewport 1440 x 900.
- In development the app exposes `window.__editor` (Zustand store) and `window.__sceneInfo`: use them for state asserts when the DOM is not enough (e.g., `await page.evaluate(() => window.__editor.getState().results?.pieces.length)`).

## Scenarios
1. Landing page loads, CTA leads to the editor.
2. First visit: the wizard appears; "Usar o chalé de exemplo" (Use the sample chalet) closes it and the panel shows the total cost in R$ and area 78,0 m².
3. Change the width (NumberInput) from 6.5 to 7.5: built area and cost change in < 1 s; undo (Ctrl+Z) returns to the previous value.
4. Click a row in the Materiais (Materials) tab sets `highlight` in the store with pieces (criterion "clicking a row highlights the pieces in 3D").
5. Reloading the page reopens the same project with the same total cost (criterion "saved and reopened reproduces the same results").
6. Export JSON (download) and reimport through the Abrir (Open) menu: same cost.
7. ART notice visible in the editor; generated PDF contains the notice (open the download and search for the text with `pdf-parse` if available; otherwise only check the download and the file name).
8. Estrutura (Structure) and Mapa de calor (Heat map) modes activate without console errors.
9. `/projetos` lists the saved project; "Novo projeto" (New project) opens the wizard.
10. New A-frame project via the wizard computes without error warnings.
11. No console errors (except expected 404s from `/api/projects/<id>` when the project exists only locally) in all scenarios.

## Acceptance
- `pnpm --filter @chalecad/web e2e` green (fixme allowed only for a real, documented bug).
