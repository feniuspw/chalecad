# F1-W1: Editor — estado, Web Worker, autosave, assistente e painel de propriedades

**Objetivo:** ligar o editor ao motor: estado global com undo/redo, cálculo no Web Worker, autosave local, assistente de novo projeto e painel de propriedades paramétricas. Ao final, mudar qualquer parâmetro atualiza o 3D na hora.

**Pode alterar:** `apps/web/lib/store/editor.ts` (+ testes), `apps/web/lib/engine/**`, `apps/web/workers/**`, `apps/web/lib/storage/indexeddb.ts`, `apps/web/lib/storage/index.ts`, `apps/web/lib/project/**`, `apps/web/components/editor/**`, `apps/web/app/editor/**`, `apps/web/hooks/**`.
**Não altere:** `apps/web/lib/store/types.ts` e `apps/web/lib/storage/types.ts` (contratos do orquestrador), `apps/web/components/scene/**` (só use os componentes; se precisar de prop nova, pare e explique), `apps/web/components/results/**`, `packages/**`, `package.json`.

O motor (`@chalecad/engine`) neste momento exporta `loadProject`, `buildModel` e o schema; `computeAll` chega em outro card. **Implemente `lib/engine/compute.ts` com `computeProject(project, catalog)` que chama `computeAll` se existir no módulo (`import * as engine`), senão monta um `Results` parcial só com `model` (demais campos vazios/zerados, tipados).** Assim o app funciona agora e passa a mostrar tudo quando o motor completo for integrado.

## Entregas
1. **Store** `lib/store/editor.ts`: `useEditor = create<EditorStore>()(...)` seguindo `lib/store/types.ts`. `update` usa `produceWithPatches` (Immer, `enablePatches()`), guarda patches/inversos, limpa `future`, incrementa `revision`, revalida com `Project.safeParse` do engine (guarda `issues`; projeto inválido continua editável, mas não recalcula). `updateCoalesced` funde entradas com mesmo label em < 600 ms. `applyPatches` (IA). Histórico ilimitado. Seletores úteis exportados (ex.: `useSelectedObject()`). Testes Vitest do store (update/undo/redo/coalesce/applyPatches/issues).
2. **Worker** `workers/engine.worker.ts` com Comlink implementando `EngineWorkerApi` (de `lib/store/types.ts`), usando `getCatalog()` de `@chalecad/catalog` e `lib/engine/compute.ts`. Cliente `lib/engine/client.ts` (singleton, `new Worker(new URL('../../workers/engine.worker.ts', import.meta.url), { type: 'module' })`). Hook `hooks/useEngine.ts`: observa `revision`, envia o projeto ao worker (último vence: descarta respostas antigas), chama `setResults`. Fallback para cálculo na thread principal se o Worker falhar (com aviso no console). Mostre o tempo de cálculo na UI.
3. **Persistência local** `lib/storage/indexeddb.ts`: `IndexedDbAdapter implements StorageAdapter` com `idb-keyval` (stores separados para projetos e versões). `lib/storage/index.ts` exporta `getStorage()` (por enquanto sempre IndexedDB). Autosave debounced (1,5 s) do projeto atual; ao abrir `/editor` sem `?id`, reabre o último projeto; com `?id=<id>` abre aquele; sem nenhum, abre o template do chalé 6,5 x 8,5. Indicador "Salvo há X s" / "Salvando…" na barra superior.
4. **Templates** `lib/project/templates.ts`: `createProject(kind, params)` para `gable_mezzanine` (igual ao fixture `packages/engine/fixtures/gable-6.5x8.5-mezzanine.json`, adaptando as aberturas às dimensões) e `a_frame` (com mezanino opcional no fundo, porta e empena frontal envidraçada); IDs novos com `crypto.randomUUID().slice(0, 8)` prefixados (`w-`, `o-`, `s-`). Helpers de edição em `lib/project/edit.ts` (puros, testados): ajustar mezanino quando a largura/profundidade muda, manter aberturas dentro das paredes ao reduzir dimensões (clamp), etc.
5. **Assistente de novo projeto** `components/editor/NewProjectDialog.tsx`: passo 1 tipologia (cards ilustrados com SVG simples de cada forma: duas águas com mezanino, A-frame; tipologias futuras aparecem desabilitadas com selo "em breve"); passo 2 dimensões principais (largura, profundidade, pé-direito/altura da cumeeira, inclinação, mezanino sim/não) com preview numérico de área; passo 3 nome e UF. Abre automaticamente no primeiro acesso.
6. **Layout do editor** (refine o que existe em `app/editor/page.tsx`, mantendo a direção visual do F0-T06): barra superior com logo, nome editável, Novo, Abrir (arquivo .json via `validate` do worker, com diálogo de erros pt-BR), Exportar JSON, Desfazer/Refazer (com tooltip mostrando o label), status de cálculo/salvamento; trilho de ferramentas à esquerda (ligado a `setTool`, atalhos V/W/O/E/M/R mostrados no tooltip); **painel esquerdo de Propriedades** (abaixo); viewport central usando `<Viewport>`/`<BuildingView>` existentes com `results.model`, hover e seleção ligados ao store; painel direito reservado para resultados (deixe um `<ResultsPanelSlot />` simples com área, nº de peças e tempo de cálculo, que outro card substitui); banner de validação quando `issues` não está vazio (lista clicável).
7. **Painel de Propriedades** `components/editor/properties/`: sem seleção, seções colapsáveis: **Tipologia** (campos da tipologia ativa com Slider + NumberInput com unidade; inclinação em graus com equivalente em %; trocar de tipologia com confirmação); **Mezanino** (liga/desliga; profundidade e posição frente/fundo; guarda-corpo); **Sistema** (espaçamento 40/60, perfis de montante/viga/caibro em Select a partir do catálogo filtrando família/alma, contraventamento OSB/fitas, assemblies externa/interna/molhada); **Cobertura** (telha, eixo da cumeeira, calhas); **Fundação** (espessura, borda, viga de borda); **Local** (UF, V0 do vento, solo). Com seleção, o inspetor do objeto: abertura (tipo, largura, altura, peitoril, posição ao longo da parede, excluir), parede interna (comprimento, área molhada, assembly, excluir), escada (tipo, largura, rotação, excluir), parede externa/água (mostra dados e lista de aberturas, botão "adicionar janela"/"adicionar porta" que cria no meio da parede). Edições via `updateCoalesced` em sliders e `update` em ações discretas.
8. **Atalhos**: Cmd/Ctrl+Z, Shift+Cmd/Ctrl+Z, Delete/Backspace (exclui seleção), Esc (limpa seleção/ferramenta), letras das ferramentas. Não disparar dentro de inputs.
