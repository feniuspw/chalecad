# F0-T06: 3D scene and the editor's visual shell

**Goal:** a 3D scene that renders a `BuildingModel` (type in `packages/engine/src/schema/results.ts`, importable from `@chalecad/engine`) and the app's visual foundation (theme, fonts, editor layout, landing page). Use a `BuildingModel` fixture generated by a script: the engine that generates the model is being built in parallel.

**May change:** `apps/web/app/**`, `apps/web/components/**`, `apps/web/fixtures/**`, `apps/web/lib/three/**`, `packages/ui/src/**`.
**Do not change:** `packages/engine/**`, `packages/catalog/**`, any `package.json` (all dependencies are already installed: three, @react-three/fiber, @react-three/drei, lucide-react, geist, radix-ui, class-variance-authority, clsx, tailwind-merge, sonner, recharts, zustand, immer, comlink). If something is missing, stop and explain.

## Visual direction (the product has to be beautiful)
- Calm professional tool, Figma/Linear style, with the warmth of wood. UI background `stone-50`/white, borders `stone-200`, text `stone-900`/`stone-600`. Amber/wood accent (`amber-600`, hover `amber-700`), `emerald-600` green for ok, `amber-500`/`red-600` for alerts.
- Geist Sans/Mono fonts via the `geist` package (`import { GeistSans } from 'geist/font/sans'`); `next/font/google` will not work (it requires network at build time). Numbers with `tabular-nums`.
- Tailwind v4 (already configured in `app/globals.css`, which already has `@source` for `packages/ui/src`). Define tokens with `@theme` (`--color-surface`, `--color-border`, `--color-accent`, `--color-ok`, `--color-warn`, `--color-fail`, etc.).
- `lucide-react` icons.
- Scene: light sky in a soft gradient behind the canvas (CSS), ground with a fine 10 cm grid and a strong line every 1 m that fades with distance (drei `<Grid infiniteGrid fadeDistance>`), soft shadows (`<ContactShadows>` or `<SoftShadows>`), `hemisphereLight` + directional light (sun). Nothing that downloads files from the network (no `<Environment preset>`). Materials: warm off-white exterior walls (#f3efe8), lighter interior walls, matte graphite roof (#3b3f45), concrete radier (raft slab) (#bdb8b0), OSB mezzanine (#c9a46a), translucent blue glass, wooden doors. Subtle edges (`<Edges>` stone-400, low opacity).
- `packages/ui/src`: Button (variants default/accent/ghost/outline/destructive, sizes sm/md/lg/icon, with cva), IconButton with Tooltip, Card (Header/Title/Content), Separator, Tooltip (radix-ui), Tabs, Slider, Switch, Select, NumberInput (with unit suffix, accepts decimal comma, step, min/max, commit on blur/Enter), Badge (ok/warn/fail/neutral/accent), Kbd, ScrollArea, Dialog, DropdownMenu, Popover. shadcn style, exported from `@chalecad/ui`.

## Deliverables
1. `app/layout.tsx` with fonts and pt-BR metadata; `app/globals.css` with the theme; sonner `<Toaster>`.
2. `app/page.tsx`: beautiful landing page (hero with the ChaléCAD name, a value statement, CTA "Abrir o editor" (Open the editor) → `/editor`, three highlights: parametric 3D model; materials, weight, and budget instantly; package for the engineer). Hero with the `<Viewport>` in showcase mode (autoRotate, no controls). ART (Anotação de Responsabilidade Técnica, the engineer's liability record) notice in the footer.
3. `app/editor/page.tsx`: full-screen editor layout, no page scroll: top bar (logo, inline-editable project name, space for actions on the right), left tool rail (icons with tooltips; no action for now), central viewport with floating controls (recenter, views), resizable right panel (placeholder "Resultados" (Results)), thin footer with the ART notice. The page uses the fixture.
4. `components/scene/`:
   - `Viewport.tsx` (client; `next/dynamic` with `ssr: false` loading `ViewportCanvas.tsx`): `<Canvas shadows dpr={[1, 2]}>`, perspective camera, `OrbitControls` (makeDefault, damping, maxPolarAngle so it does not go below the ground), automatic framing from `model.bbox`, `showcase` prop, ref/imperative "recenter" and predefined views (3D, top, front, side).
   - Convention: engine z-up → scene y-up in a single `<group rotation={[-Math.PI/2, 0, 0]}>`; `toThree([x,y,z]) => [x, z, -y]` only for camera/bbox. Document it in `lib/three/convert.ts`.
   - `BuildingView.tsx` (`model: BuildingModel`, `highlight?: { hostIds: string[] }`, `onSelectHost?(id)`, `hoverable`): walls as a `THREE.Shape` of the `outline` with `holes` for each valid opening, `ExtrudeGeometry` with `depth = thickness`, centered on the axis; openings (glass and door leaf); roof planes as ~4 cm slabs; slabs (radier extruded downward, mezzanine); guardrail on the free edge of the mezzanine; stairs (`treads`). Hover highlights the piece (slight emissive), click selects (amber outline). Memoized geometries.
   - `lib/three/convert.ts`: pure, testable helpers (without importing three): `toThree`, `wallBasis`, `wallShapeParams` (outline + holes), opening placement, roof slab basis, free edges of the mezzanine. Vitest tests in `lib/three/convert.test.ts`.
5. `fixtures/make-model.mjs` generating `fixtures/model-gable.json`: a coherent `BuildingModel` of a 6.5 x 8.5 m chalet, ceiling height 2.8, 35° roof, ridge along y, eave 0.6, rake 0.3, pentagonal gable ends (ext-front/ext-back), a door and 2 windows on the front, 1 window per side wall, radier, mezzanine at y 5..8.5 at 2.8 m, straight stair with 16 risers, wall thickness 0.14.
