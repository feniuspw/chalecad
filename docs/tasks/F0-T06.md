# F0-T06: Cena 3D e casca visual do editor

**Objetivo:** cena 3D que renderiza um `BuildingModel` (tipo em `packages/engine/src/schema/results.ts`, importável de `@chalecad/engine`) e a base visual do app (tema, fontes, layout do editor, landing). Use uma fixture de `BuildingModel` gerada por script: o motor que gera o modelo está sendo feito em paralelo.

**Pode alterar:** `apps/web/app/**`, `apps/web/components/**`, `apps/web/fixtures/**`, `apps/web/lib/three/**`, `packages/ui/src/**`.
**Não altere:** `packages/engine/**`, `packages/catalog/**`, nenhum `package.json` (todas as dependências já estão instaladas: three, @react-three/fiber, @react-three/drei, lucide-react, geist, radix-ui, class-variance-authority, clsx, tailwind-merge, sonner, recharts, zustand, immer, comlink). Se faltar algo, pare e explique.

## Direção visual (o produto tem que ser bonito)
- Ferramenta profissional calma, tipo Figma/Linear, com calor de madeira. Fundo da UI `stone-50`/branco, bordas `stone-200`, texto `stone-900`/`stone-600`. Acento âmbar/madeira (`amber-600`, hover `amber-700`), verde `emerald-600` para ok, `amber-500`/`red-600` para alertas.
- Fontes Geist Sans/Mono via pacote `geist` (`import { GeistSans } from 'geist/font/sans'`); `next/font/google` não serve (exige rede no build). Números com `tabular-nums`.
- Tailwind v4 (já configurado em `app/globals.css`, que já tem `@source` para `packages/ui/src`). Defina tokens com `@theme` (`--color-surface`, `--color-border`, `--color-accent`, `--color-ok`, `--color-warn`, `--color-fail` etc.).
- Ícones `lucide-react`.
- Cena: céu claro em gradiente suave atrás do canvas (CSS), chão com grade fina 10 cm e linha forte a cada 1 m que esmaece com a distância (drei `<Grid infiniteGrid fadeDistance>`), sombras suaves (`<ContactShadows>` ou `<SoftShadows>`), `hemisphereLight` + direcional (sol). Nada que baixe arquivos da rede (sem `<Environment preset>`). Materiais: paredes externas off-white quente (#f3efe8), internas mais claras, telhado grafite (#3b3f45) fosco, radier concreto (#bdb8b0), mezanino OSB (#c9a46a), vidro azul translúcido, portas madeira. Arestas sutis (`<Edges>` stone-400, opacidade baixa).
- `packages/ui/src`: Button (variants default/accent/ghost/outline/destructive, sizes sm/md/lg/icon, com cva), IconButton com Tooltip, Card (Header/Title/Content), Separator, Tooltip (radix-ui), Tabs, Slider, Switch, Select, NumberInput (com sufixo de unidade, aceita vírgula decimal, step, min/max, commit no blur/Enter), Badge (ok/warn/fail/neutral/accent), Kbd, ScrollArea, Dialog, DropdownMenu, Popover. Estilo shadcn, exportados de `@chalecad/ui`.

## Entregas
1. `app/layout.tsx` com fontes e metadata pt-BR; `app/globals.css` com tema; `<Toaster>` do sonner.
2. `app/page.tsx`: landing bonita (hero com nome ChaléCAD, frase de valor, CTA "Abrir o editor" → `/editor`, três destaques: modelo 3D paramétrico; materiais, peso e orçamento na hora; pacote para o engenheiro). Hero com o `<Viewport>` em modo showcase (autoRotate, sem controles). Aviso de ART no rodapé.
3. `app/editor/page.tsx`: layout do editor em tela cheia, sem scroll de página: barra superior (logo, nome do projeto editável inline, espaço para ações à direita), trilho esquerdo de ferramentas (ícones com tooltip; por enquanto sem ação), viewport central com controles flutuantes (centralizar, vistas), painel direito redimensionável (placeholder "Resultados"), rodapé fino com o aviso de ART. A página usa a fixture.
4. `components/scene/`:
   - `Viewport.tsx` (client; `next/dynamic` com `ssr: false` carregando `ViewportCanvas.tsx`): `<Canvas shadows dpr={[1, 2]}>`, câmera perspectiva, `OrbitControls` (makeDefault, damping, maxPolarAngle para não passar do chão), enquadramento automático pelo `model.bbox`, prop `showcase`, ref/imperative "centralizar" e vistas pré-definidas (3D, topo, frente, lateral).
   - Convenção: motor z-up → cena y-up num único `<group rotation={[-Math.PI/2, 0, 0]}>`; `toThree([x,y,z]) => [x, z, -y]` só para câmera/bbox. Documente em `lib/three/convert.ts`.
   - `BuildingView.tsx` (`model: BuildingModel`, `highlight?: { hostIds: string[] }`, `onSelectHost?(id)`, `hoverable`): paredes como `THREE.Shape` do `outline` com `holes` para cada abertura válida, `ExtrudeGeometry` com `depth = thickness`, centrada no eixo; aberturas (vidro e folha de porta); águas do telhado como placas com ~4 cm; lajes (radier extrudado para baixo, mezanino); guarda-corpo na borda livre do mezanino; escadas (`treads`). Hover destaca a peça (emissive leve), clique seleciona (contorno âmbar). Geometrias memoizadas.
   - `lib/three/convert.ts`: helpers puros testáveis (sem importar three): `toThree`, `wallBasis`, `wallShapeParams` (outline + furos), posicionamento de aberturas, base de laje de telhado, bordas livres do mezanino. Testes Vitest em `lib/three/convert.test.ts`.
5. `fixtures/make-model.mjs` gerando `fixtures/model-gable.json`: `BuildingModel` coerente de um chalé 6,5 x 8,5 m, pé-direito 2,8, telhado 35°, cumeeira em y, beiral 0,6, rake 0,3, empenas pentagonais (ext-front/ext-back), porta e 2 janelas na frente, 1 janela por lateral, radier, mezanino em y 5..8,5 a 2,8 m, escada reta de 16 espelhos, espessura de parede 0,14.
