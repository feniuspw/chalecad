# F10-W2: App — end-to-end tests for the new flows (Playwright)

**Goal:** cover with e2e the flows added in phases 5 through 9, so the user does not run into regressions. The tests run with `pnpm --filter @chalecad/web e2e`, which already has config, a temporary database, and port 3110.

**May change:**
- `apps/web/e2e/**`.
- `apps/web/playwright.config.ts`, only if needed (timeout, for example).
- Small `data-testid` attributes on existing components, only where there is no stable role/label selector. Do not change behavior.
  - Forbidden in these files (from F8-W2 and F10-W1, in parallel): `components/editor/EditorShell.tsx`, `NewProjectDialog.tsx`, `components/onboarding/**`, `components/projects/**`, `components/viewer/**`, `app/ver/**`, and `TopBar.tsx`.
  - If you need a selector in them, use role/text.

**Do not change:** `packages/**`, `lib/store/**`, and `package.json`.

## Flows (one `test` each, independent)
1. **Rooms:** create a project (wizard) → Room tool → click inside → choose "Quarto" (Bedroom) → the inspector shows area > 0 and the label appears on the floor plan.
2. **Finishes:** choose flooring and facade → the budget now has the flooring line (Materials/Budget tab).
3. **Furniture:**
   - open the library (key `F`), choose "Cama de casal" (Double bed), click inside the room → the furniture item appears in the room's list;
   - `R` rotates and `Delete` removes;
   - "Mobiliar" (Furnish) in the bedroom adds at least 2 items.
4. **Fit to codes:** open the dialog and see the before/after counts. Apply and undo (Ctrl/⌘+Z) restores the cost.
5. **Installations:** turn on in Properties → the "Instalações" (Installations) tab appears with at least 1 circuit (with one room marked).
6. **Wood frame:** switch the system → the KPI shows "Madeira" (Wood) and the material list has wood pieces.
7. **Performance:** the "Desempenho" (Performance) tab shows the wall card with U; turning on solar power shows kWp.
8. **Construction:** the "Obra" (Construction) tab → set the start date → mark an item as purchased → the total paid changes.
9. **Presentation:** click "Apresentação" (Presentation) → the sun panel appears; changing the time does not produce a console error.
10. **Export DXF:** the download starts and the file begins with `0\nSECTION` (read by Playwright).
- In all of them: zero unexpected `pageerror` / `console.error`. Put together an explicit ignore list, if there is known noise from three or Next.

## Acceptance tests
- `pnpm --filter @chalecad/web e2e` green locally: all new tests and the old ones.
- If a flow finds a real application bug, do not fix it in the components. Mark the test with `test.fixme` and describe the bug in the return (file, step, error), for the orchestrator to fix.
- `pnpm --filter @chalecad/web typecheck` and `lint` green.
- In the return: the result of each flow, the bugs found, and the total suite time.
