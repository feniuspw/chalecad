# F7-W2: App — export DXF (floor plan per level and elevations) for AutoCAD

**Goal:** the engineer or architect opens the project in AutoCAD, LibreCAD, or QCAD. The Export menu produces a DXF with the floor plan of each level and the four elevations, in meters, separated by layers.

**May change:**
- `apps/web/lib/export/dxf.ts` (new) and the test next to it.
- `apps/web/components/editor/TopBar.tsx`, only for the "DXF (AutoCAD)" item in the Export menu.
- `apps/web/lib/plan2d/**`, read-only. If you need a new geometry function, create it in `lib/export/` and do not change `lib/plan2d`, which belongs to F7-W1 in parallel.

**Do not change:** `packages/**`, `lib/store/**`, `package.json`, `components/scene/**`, and `components/results/**`. Do not add a dependency: write the DXF as text, in ASCII R12 or minimal AC1015 format, which every program reads.

## 1. DXF writer (`lib/export/dxf.ts`)
- Build a minimal, pure writer:
  - `HEADER` with `$INSUNITS = 6` (meters) and `$ACADVER`;
  - `TABLES` with `LAYER` (name and ACI color) and `LTYPE` (CONTINUOUS and DASHED);
  - `ENTITIES` with `LINE`, `LWPOLYLINE` (or `POLYLINE`/`VERTEX` in R12), `CIRCLE`, `ARC`, `TEXT`, and optional `HATCH`;
  - `EOF`.
- Layers, with ACI colors:
  - `PAREDES` (7), `PAREDES-INT` (8), `ABERTURAS` (4), `ESCADA` (6);
  - `COMODOS` (3, name and area text), `MOVEIS` (9), `COTAS` (2);
  - `FACHADA` (7), `TELHADO` (1), `EIXOS` (DASHED), `TEXTO` (7).
- Coordinates in meters, same as the engine's (x, y in plan).

## 2. Content
- **Floor plan of each level**, side by side, with an x offset of width + 3 m:
  - walls as two lines (faces) from `model.walls` (axis ± thickness/2), with the openings cutting the face;
  - doors with a swing arc and windows with three lines;
  - stair with steps and an arrow;
  - rooms with name and area at the centroid (reuse `lib/plan2d/rooms.ts` for the label);
  - furniture with the strokes from `lib/plan2d/furnitureSymbols.ts`;
  - simple overall dimensions (line + text), one horizontal and one vertical per plan;
  - title "TÉRREO" (GROUND FLOOR) / "MEZANINO" (MEZZANINE).
- **Elevations** below the floor plans (front, back, left, right): outline of the walls, openings, and roof, projected from `lib/plan2d/elevation.ts` if a projection is already available; otherwise, project the outlines of `model.walls` and `model.roofPlanes`.
- **Title block (carimbo)** in the corner: project name, date, area, and the notice "Estimativa — não substitui projeto com ART".

## 3. Menu
- "Exportar → DXF (AutoCAD)" (Export → DXF (AutoCAD)) downloads `project-name.dxf`, through the existing `lib/export/download.ts`.

## Acceptance tests
- The DXF generated from the fixture starts with `0\nSECTION`, has `HEADER`, `TABLES`, and `ENTITIES`, and ends with `0\nEOF`.
  - Well-formed code/value pairs (even number of lines).
  - All layers used are declared.
- Count: a 4 m wall with no opening generates 2 `LINE`s (or one closed polyline) on the `PAREDES` layer. A door generates an `ARC`.
- The room text "Quarto · 9,0 m²" is output in UTF-8 (`$DWGCODEPAGE` ANSI_1252, if R12, with accents converted safely) and does not break the file.
- If you can, validate by opening it with a parser (no new dependency: just a test that rereads the pairs).
- `pnpm --filter @chalecad/web typecheck`, `lint`, `test`, and `build` green. Run the commands separately.
- In the return: the chosen format, how to verify, and what was left out.
