# F2-W1: Editor — all typologies, extras, terrain, and variant comparison

**Goal:** expose in the editor everything the engine already calculates from Phases 2 to 4: shed, flat-roof, gambrel, and L/T module typologies; extras (deck, wall, fence, retaining wall); sloped terrain; and side-by-side comparison of two variants with cost and weight differences.

**May change:** `apps/web/components/editor/properties/**`, `apps/web/components/editor/NewProjectDialog.tsx`, `apps/web/components/editor/TypologyIllustrations.tsx`, `apps/web/components/compare/**` (new), `apps/web/lib/project/**` (+ tests), `apps/web/app/comparar/**` (if you make a route).
**Do not change:** `lib/store/types.ts`, `components/scene/**`, `components/results/**`, `packages/**`, `package.json`. For the "Comparar" (Compare) button in the top bar, describe in the return where to fit it (the orchestrator wires it).

## Deliverables
1. **Wizard** (`NewProjectDialog`): enable shed, flat roof, gambrel, and L/T modules (remove the "em breve" (coming soon) badge), with illustrations and the dimensions step specific to each (schema fields in `packages/engine/src/schema/project.ts`). Optional extra step "Terreno" (Terrain): flat or sloped (slope %, direction it descends via a visual 4-direction selector + angle).
2. **Templates** (`lib/project/templates.ts`): `createProject` for all typologies, with coherent openings (door at the front, windows on the sides); for L/T, an opening in the wing. Tests: each template validates against the schema and runs `computeAll` without error.
3. **Typology properties**: sections for the fields of each new typology (shed: low/high heights, high side; flat roof: parapet, slope; gambrel: angles and break; L/T: shape, wing width/depth/position). Switching typology preserves width/depth and valid openings (`lib/project/edit.ts`).
4. **Terrain section**: flat or sloped; slope, descent direction (visual selector), plateau margins per side, plateau elevation (auto or manual with slider), cut/fill slopes (H:V), distance to the spoil (bota-fora) disposal site. Shows a summary from `results.terrain` (cut, fill, export) right there.
5. **Extras section**: list of extras with icon and summary; add **Varanda/deck** (Porch/deck; side, length, setback, depth, height, covered, guardrail), **Muro** (Wall) and **Cerca** (Fence) (by default a rectangular path around the house with a 3 m clearance, numerically editable: list of vertices with x/y; the drawing in 3D is wired by the orchestrator via `PathDrawer`), **Muro de arrimo** (Retaining wall; path, height, type, drainage). Extra inspector when `selection.kind === 'extra'`. Delete/duplicate.
6. **Variant comparison** (`components/compare/CompareDialog.tsx`): choose variant B from: a saved named version (via `getStorage().listVersions/getVersion`), "same project with another typology" (generated with `lib/project/edit.ts` by switching the typology), or "40 cm spacing"/"another pitch" (shortcuts). Computes A and B in the worker (`EngineWorkerApi.computeMany`, client in `lib/engine/client.ts`) and shows side by side: 3D thumbnails (reuse `<Viewport showcase>` from `components/scene` with the `model` of each result), difference table (total cost and range, R$/m², built area, total weight, steel kg/m², piece count, worst structural ratio, warning count) with arrows and colors (green = better), and differences per budget stage. "Usar variante B" (Use variant B) button (loads with `update`, undoable).
