# F2-E1: Structural engine — loads, usage ratios, and suggestions

**Goal:** simplified preliminary sizing that generates the `StructuralReport` (types in `packages/engine/src/schema/results.ts`) and feeds the "heatmap" mode. It never states "approved": status `ok` = "within the usual range", `warn`/`fail` = "needs engineer review".

**May change:** `packages/engine/src/structure/**`, `packages/engine/src/compute.ts` (only to call `computeStructure` and fill `results.structure`, plus the time in `timingsMs.structure`), `packages/engine/src/index.ts` (exports), `packages/engine/test/structure/**`.
**Do not change:** `src/schema/**`, `src/model/**`, `src/framing/**`, `src/quantities/**`, `src/budget/**`, `packages/catalog/**`.

## API
```ts
export function computeStructure(ctx: { project: Project; model: BuildingModel; pieces: Piece[]; weight: WeightReport; catalog: Catalog }): StructuralReport;
```
All constants from `catalog.constants` (`loads`, `deflection` as denominators, `usage`, `anchorage`, `bracingMinRatio`, `steelE`), section properties of the catalog profiles (`area`, `Ix`, `Wx`, `rx`, `ry`, `fy` — units cm/cm²/cm³/cm⁴/MPa: convert carefully and test the conversions).

## Loads (kPa)
- Roof dead load = self-weight (roof panel + purlins + rafters per m² of roof, from `weight.byElement` of the roof planes / area) + `superimposedRoof`. Roof live load `liveRoof`.
- Mezzanine floor: self-weight (OSB + joists per m²) + `superimposedFloor`; live load `liveMezzanine`.
- Wind (simplified NBR 6123): Vk = V0 · S1 · S2(category) · S3; q = 0.613 · Vk² (N/m² → kPa). Wall: q·(cpeWall + |cpi|). Roof (uplift): q·(cpeRoofUplift + cpi).
- ULS (ELU) combinations: 1.4·G + 1.5·Q (gravity); 0.9·G − 1.4·W (uplift/pull-out); compression + wind bending for studs: 1.4·G + 1.5·Q + 0.6·1.4·W and a variant with wind as the main action.

## Checks (one `StructuralCheck` per representative group, with `pieceIds` and `hostIds` for coloring)
1. **Studs** (per exterior wall; and walls that support the mezzanine): axial load per stud = influence area (spacing × half-width of the roof and/or mezzanine span that the wall receives) × load; simplified compression resistance per NBR 14762: Ne = π²·E·A/(K·L/r)² with K = 1, L = stud height, r = rx (buckling in the plane braced by the boards/blocking uses ry with L = blocking spacing; use the smaller Ne); λ0 = √(A·fy/Ne); χ = 0.658^(λ0²) if λ0 ≤ 1.5, else 0.877/λ0²; Nc,Rd = χ·A·fy/1.2 (effective-area factor 0.85 for thin sheets, document it). Wind bending: M = qw·s·L²/8; Mrd = Wx·fy/1.1. Interaction N/Nrd + M/Mrd.
2. **Mezzanine joists** (longest span): M = q·s·L²/8 vs Wx·fy/1.1; V = q·s·L/2 vs 0.6·fy·(web·t)/1.1; deflection 5·q·L⁴/(384·E·I) vs L/deflection.floor (service load G+Q). Ratio = the maximum of the three.
3. **Rafters** (longest horizontal length): gravity and uplift, moment and deflection (L/deflection.roof).
4. **Purlins/hat sections (cartolas)**: span = rafterSpacing, roof panel load and wind; moment with the hat section's Wx.
5. **Headers** (each opening with span > 1 m, grouping identical ones): load from the wall/roof section above × span; box header = 2 × the profile's Wx.
6. **Bracing**: per direction (x and y), length of braced exterior wall (OSB: walls with no openings in panels ≥ 1.2 m; straps: panels with X) / total facade length in that direction; demand = `bracingMinRatio`, capacity = the ratio obtained (ratio = demand/capacity).
7. **Anchorage**: total uplift = roof suction × plan area − 0.9 × self-weight of the superstructure; capacity = number of anchor bolts (from the calculated quantity) × anchorKN + hold-downs × holdDownKN.
8. **Radier (raft slab)**: average pressure = total weight (including the radier) + live loads / radier area, vs `project.design.soilBearingKPa`.

`status`: ratio < usage.warn → ok; ≤ usage.fail → warn; > fail → fail. `detail` in pt-BR with the numbers and a short formula (e.g., "N = 4,2 kN; Nc,Rd = 11,8 kN (χ = 0,62, λ0 = 1,05)").

**Suggestions** (status warn/fail): for studs/joists/rafters, look in the catalog for the next profile of the same family with larger Wx/area (same web with greater thickness, then larger web) and/or 0.4 spacing when it is at 0.6; recompute the ratio with the new profile; `deltaKg` = Σ length of the affected pieces × (new mass − current); approximate `deltaCost` = deltaKg × (price per kg of the new profile's 6 m bar, from the price book). Text: "Trocar Ue90x40x0.95 por Ue90x40x1.25 deixa a taxa em 0,78 (+38 kg, +R$ 610)" (Swapping Ue90x40x0.95 for Ue90x40x1.25 brings the ratio to 0.78 (+38 kg, +R$ 610)).

`summary` and `disclaimer` = `DISCLAIMER`. `loads` filled in.

## Acceptance tests (literature + by hand)
- Wind: V0 = 35, cat. 3 → Vk = 32.9 m/s, q ≈ 0.664 kPa (±1%).
- Textbook simply supported beam example: Ue200x40x1.25, L = 3.5 m, q = 2.5 kN/m → M, deflection, and ratios checked by hand in the test (document the calculation).
- Compression of stud Ue90x40x0.95 with L = 2.8 m: Nc,Rd checked by hand.
- 6.5 x 8.5 fixture: all checks appear; 6.5 m mezzanine joists in Ue200x40x1.25 should give warn/fail with a suggestion (large span) — document the value; studs ok.
- Ratios and status deterministic; no NaN; `computeAll` fills `structure`.
- `computeStructure` < 20 ms on the fixture.
