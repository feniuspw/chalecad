# F0-T05: Engine — loadProject and buildModel (building geometry)

**Goal:** transform a validated project into the `BuildingModel` (`packages/engine/src/schema/results.ts`) for the `gable_mezzanine` and `a_frame` typologies. Pure functions, no Three.js, no browser, no Node.

**May change:** `packages/engine/src/load/**`, `packages/engine/src/geometry/**`, `packages/engine/src/model/**`, `packages/engine/src/index.ts` (only add exports), `packages/engine/test/**` (except `test/schema/`).
**Do not change:** `packages/engine/src/schema/**`, `packages/catalog/**`.

## API
```ts
// src/load/index.ts
export type LoadResult =
  | { ok: true; project: Project; migrated: boolean }
  | { ok: false; issues: { path: string; message: string }[] };
export function loadProject(json: unknown): LoadResult;
// accepts a string (JSON.parse; a syntax error becomes an issue with path '') or an object;
// migrations: Record<number, (p: any) => any> (empty), applied when schemaVersion < SCHEMA_VERSION;
// messages in pt-BR (translate the most common Zod ones: required, invalid type, min/max, enum, union).

// src/model/index.ts
export function buildModel(project: Project, catalog: Catalog): BuildingModel;
```
`import type { Catalog } from '@chalecad/catalog'` (the catalog index exports the schema). The catalog DATA is being written in parallel by another agent: in tests use a minimal catalog in `test/helpers/catalog.ts`, built by hand and valid under the `Catalog` schema (profiles Ue90/U90/Ue140/Ue200/U200/Cr50, the fixture's materials and assemblies with thicknesses, an empty price book, and complete `constants`; see the values in `docs/tasks/F0-T04.md` item 6). Wall thickness = `wallStud` web (mm) + sum of the assembly layer thicknesses, in meters. Missing profile: error; missing assembly: error with a pt-BR message.

## Geometry rules
Read the top of `packages/engine/src/schema/project.ts`. Origin at the front-left corner; x = width, y = depth, z up. `width/depth` are axis to axis of the exterior walls; `footprint` is the outer outline (axis + half thickness).

**gable_mezzanine**
- Exterior walls `ext-front` ([0,0]→[w,0]), `ext-right` ([w,0]→[w,d]), `ext-back` ([w,d]→[0,d]), `ext-left` ([0,d]→[0,0]): counterclockwise seen from above, `exteriorSide: 'right'`, `kind: 'exterior'`, `loadBearing: true`.
- `roof.ridgeAxis = 'depth'`: ridge parallel to y at x = w/2, height `wallHeight + (w/2)·tan(pitch)`. Gable ends = `ext-front` and `ext-back` with a pentagonal outline (rectangle + triangle up to the ridge). Side walls rectangular with height wallHeight. `ridgeAxis = 'width'`: the reverse.
- Roof planes `roof-a` (-x or -y side) and `roof-b`: 3D rectangles with eave `eave` (horizontal projection beyond the axis, at the same slope) and `rake` (extension beyond the gable ends). `area` = uLength × vLength with vLength = (half-width + eave)/cos(pitch). Reference frame: origin at the eave corner, uAxis along the eave, vAxis going up; uAxis × vAxis points outward; vertices counterclockwise seen from outside.
- Slabs: `radier` (raft slab; footprint expanded by `system.foundation.border`, topZ 0, thickness = foundation.thickness, level 'L0'); `mezzanine` for each level with `polygon` (topZ = elevation, thickness = joist web + 18 mm).
- `ridgeHeight`, `bbox` (includes eaves and the radier below 0), `footprintArea`, `builtArea` = w·d (axis to axis) + mezzanine area.

**a_frame**
- Roof planes that descend to z = `kneeWallHeight` at x = 0 and x = w (ridge at x = w/2 at `ridgeHeight`; always ridgeAxis depth). `isWall: true`. No eave; `rake` extends at the front/back.
- `kneeWallHeight > 0`: walls `ext-left`/`ext-right` kind `'knee'` with that height.
- Gable ends `ext-front` and `ext-back` with a triangular outline (trapezoid + triangle with a knee wall), kind `'gable'`, `assemblyId` = `'gable_glazed'` if 'glazed', the exterior one if 'closed'; 'open' → no wall.
- Mezzanine as in the gable.

**User walls**: `kind 'interior'`, baseZ = level elevation; height = `height` or the next level above or, on the gable's ground floor, `wallHeight`; above the ground floor and in the A-frame, roof height at the midpoint capped by `constants.defaultCeilingMax`. `assemblyId` = `assembly` ?? (`wet` ? system.assemblies.wet : system.assemblies.interior). `exteriorSide: null`; `loadBearing` true only if it coincides (±5 cm) with a mezzanine edge.

**Openings**: wall → u0 = offset, u1 = offset + width, v0 = sill (door/sliding_door: 0), v1 = v0 + height; roof (skylight) → u, v of the RoofPlane. `valid = false` if the host does not exist, the type is incompatible (skylight on a wall, window/door on a roof), or the rectangle falls outside the outline (tolerance 1e-6; for a gable end, check that all 4 corners are inside the polygon).

**Stairs**: height = `to` elevation − `from` elevation; risers n = ceil(height / constants.stairs.idealRiser); riser = height/n; going = constants.stairs.going (ladder: ladderGoing, width 0.5); `position` = left corner of the foot looking up the stair; climb direction (sin r, cos r) with r = rotationDeg; n−1 treads (the last riser reaches the upper floor), boxes `[width, going, treadThickness]` with `rotationZDeg = -rotationDeg`; l_shape: square landing (width × width) at the midpoint. `blondel = 2·riser + going`. `footprint` = rectangle(s) in plan.

**Utility geometry** (`src/geometry/`): area (shoelace), point in polygon, bbox, offset of a convex/rectangular polygon, length, normalization, Vec2/Vec3. Tests for each. Normalize `-0` to `0` in the output.

## Acceptance tests
- `loadProject`: valid fixtures ok; each invalid one with issues and path; broken JSON; pt-BR messages.
- 6.5 x 8.5 fixture (pitch 35°, eave 0.6, rake 0.3): ridgeHeight = 2.8 + 3.25·tan35° (±1 mm); area of each roof plane = (3.25+0.6)/cos35° × (8.5+0.6) (±1%); 4 exterior walls + 2 interior; ext-front with 5 vertices; all openings valid; mezzanine 6.5×3.5; stair with 16 risers and riser 0.175.
- Minimal A-frame: two isWall roof planes, front gable end with `gable_glazed`, valid door (fits in the triangle).
- Opening outside the host and nonexistent host → valid false.
- Result is JSON-serializable (`JSON.parse(JSON.stringify(m))` deep-equal).
- buildModel of the fixture < 5 ms (average of 100).
