## Regras de geometria
Leia o topo de `packages/engine/src/schema/project.ts`. Origem no canto frente-esquerda; x = largura, y = profundidade, z para cima. `width/depth` são de eixo a eixo das paredes externas; `footprint` é o contorno externo (eixo + meia espessura).

**gable_mezzanine**
- Paredes externas `ext-front` ([0,0]→[w,0]), `ext-right` ([w,0]→[w,d]), `ext-back` ([w,d]→[0,d]), `ext-left` ([0,d]→[0,0]): anti-horário visto de cima, `exteriorSide: 'right'`, `kind: 'exterior'`, `loadBearing: true`.
- `roof.ridgeAxis = 'depth'`: cumeeira paralela a y em x = w/2, altura `wallHeight + (w/2)·tan(pitch)`. Empenas = `ext-front` e `ext-back` com outline pentagonal (retângulo + triângulo até a cumeeira). Laterais retangulares de altura wallHeight. `ridgeAxis = 'width'`: o inverso.
- Águas `roof-a` (lado -x ou -y) e `roof-b`: retângulos 3D com beiral `eave` (projeção horizontal além do eixo, na mesma inclinação) e `rake` (prolongamento além das empenas). `area` = uLength × vLength com vLength = (meia-largura + eave)/cos(pitch). Referencial: origin no canto do beiral, uAxis ao longo do beiral, vAxis subindo; uAxis × vAxis aponta para fora; vértices anti-horários vistos de fora.
- Lajes: `radier` (footprint expandido por `system.foundation.border`, topZ 0, thickness = foundation.thickness, level 'L0'); `mezzanine` para cada nível com `polygon` (topZ = elevation, thickness = alma do joist + 18 mm).
- `ridgeHeight`, `bbox` (inclui beirais e o radier abaixo de 0), `footprintArea`, `builtArea` = w·d (eixo a eixo) + área dos mezaninos.

**a_frame**
- Águas que descem até z = `kneeWallHeight` em x = 0 e x = w (cumeeira em x = w/2 a `ridgeHeight`; sempre ridgeAxis depth). `isWall: true`. Sem beiral; `rake` prolonga na frente/fundo.
- `kneeWallHeight > 0`: paredes `ext-left`/`ext-right` kind `'knee'` com essa altura.
- Empenas `ext-front` e `ext-back` com outline triangular (trapézio + triângulo com mureta), kind `'gable'`, `assemblyId` = `'gable_glazed'` se 'glazed', a externa se 'closed'; 'open' → sem parede.
- Mezanino como no gable.

**Paredes do usuário**: `kind 'interior'`, baseZ = elevação do nível; altura = `height` ou próximo nível acima ou, no térreo do gable, `wallHeight`; acima do térreo e no A-frame, altura do telhado no ponto médio limitada por `constants.defaultCeilingMax`. `assemblyId` = `assembly` ?? (`wet` ? system.assemblies.wet : system.assemblies.interior). `exteriorSide: null`; `loadBearing` true só se coincidir (±5 cm) com uma borda de mezanino.

**Aberturas**: parede → u0 = offset, u1 = offset + width, v0 = sill (door/sliding_door: 0), v1 = v0 + height; telhado (skylight) → u, v do RoofPlane. `valid = false` se host inexistente, tipo incompatível (skylight em parede, janela/porta em telhado) ou retângulo fora do outline (tolerância 1e-6; para empena, cheque os 4 cantos dentro do polígono).

**Escadas**: altura = elevação `to` − `from`; espelhos n = ceil(altura / constants.stairs.idealRiser); riser = altura/n; going = constants.stairs.going (ladder: ladderGoing, largura 0,5); `position` = canto esquerdo do pé olhando a subida; direção de subida (sin r, cos r) com r = rotationDeg; n−1 degraus (o último espelho chega no piso superior), caixas `[width, going, treadThickness]` com `rotationZDeg = -rotationDeg`; l_shape: patamar quadrado (largura × largura) na metade. `blondel = 2·riser + going`. `footprint` = retângulo(s) em planta.

**Geometria utilitária** (`src/geometry/`): área (shoelace), ponto em polígono, bbox, offset de polígono convexo/retangular, comprimento, normalização, Vec2/Vec3. Testes para cada uma. Normalize `-0` para `0` na saída.
