# F1-W4: Persistência SQLite, lista de projetos, versões nomeadas e PDF

**Objetivo:** salvar projetos no servidor local (Drizzle + SQLite, `DATA_MODE=sqlite`), página de projetos, versões nomeadas e exportação PDF com plantas e lista de materiais.

**Pode alterar:** `apps/web/lib/db/**`, `apps/web/lib/storage/http.ts`, `apps/web/lib/storage/index.ts`, `apps/web/app/api/**`, `apps/web/app/projetos/**`, `apps/web/lib/pdf/**`, `apps/web/components/pdf/**`, `apps/web/components/projects/**`, `apps/web/components/editor/VersionsDialog.tsx` (novo), `apps/web/scripts/**`, `apps/web/drizzle.config.ts`, `apps/web/lib/plan2d/**` (+ testes).
**Não altere:** contratos em `lib/store/types.ts` e `lib/storage/types.ts`, `components/scene/**`, `components/results/**`, `packages/**`, `package.json`. Para ligar botões novos no editor (Versões, PDF, link para Projetos), descreva no retorno exatamente onde e como; o orquestrador encaixa. Exceção: pode editar `apps/web/components/editor/TopBar.tsx` (ou o arquivo equivalente da barra superior) só para adicionar esses 3 botões.

## Entregas
1. **Banco** `lib/db/`: schema Drizzle (`projects`: id, name, typology, data JSON, builtArea, total, thumbnail, createdAt, updatedAt; `versions`: id, projectId, name, data JSON, createdAt) para SQLite (better-sqlite3, arquivo `./data/chalecad.sqlite` relativo à raiz do app, criado se não existir). `scripts/migrate.mjs` cria as tabelas (DDL idempotente; `pnpm db:migrate`). Migração automática na primeira conexão também. Abstração `getDb()` que lê `DATA_MODE` (`sqlite` padrão; `supabase` lança erro claro "não configurado neste ambiente").
2. **API** (route handlers, `runtime = 'nodejs'`): `GET/POST /api/projects`, `GET/PUT/DELETE /api/projects/[id]`, `GET/POST /api/projects/[id]/versions`, `GET/DELETE /api/versions/[id]`. Validação do corpo com o `Project` schema do engine (Zod). Erros JSON com mensagem pt-BR.
3. **HttpAdapter** `lib/storage/http.ts` implementando `StorageAdapter`. `lib/storage/index.ts`: `getStorage()` usa HttpAdapter quando a API responde (checagem `/api/health`, crie essa rota) e cai para IndexedDB offline; mantenha a função `getLocalStorage()` (IndexedDB) para o autosave rápido.
4. **Página `/projetos`**: grade de cards bonitos (nome, tipologia com ícone, área, custo total, atualizado há X, miniatura se houver), busca, ordenar, "Novo projeto" (vai para `/editor?new=1`), duplicar, renomear, excluir com confirmação, importar JSON. Estado vazio convidativo.
5. **Versões nomeadas** `components/editor/VersionsDialog.tsx`: salvar versão com nome, listar, restaurar (carrega no editor com `loadProject`, após confirmação), comparar rapidamente (mostra diferença de área/custo/peso se `results` disponíveis via `EngineWorkerApi.computeMany`, opcional), excluir.
6. **Plantas 2D** `lib/plan2d/`: funções puras que geram SVG (string) a partir do `BuildingModel`: planta por nível (paredes com espessura e hachura, aberturas com arco de porta e janela em linha tripla, escada com setas, mezanino tracejado no térreo, cotas externas e internas principais, norte e escala gráfica), fachadas frontal e lateral (contornos de paredes, telhado, aberturas). Testes: SVG válido e contém os elementos esperados.
7. **PDF** `lib/pdf/` + `components/pdf/` com `@react-pdf/renderer` (gerado no cliente, download): capa (nome, data, tipologia, área, total, aviso de ART em destaque), plantas e fachadas (SVG → `<Svg>` do react-pdf ou imagem PNG via canvas), quadro de áreas, lista de materiais por etapa (tabela), orçamento por etapa com totais e faixa, alertas, premissas (perfis, espaçamento, assemblies, base de preços e data). **Aviso de ART no rodapé de todas as páginas.** Numeração de páginas. Tipografia limpa (Helvetica embutida do react-pdf).
8. Função `exportPdf(project, results)` exportada de `lib/pdf/index.ts` para o editor chamar.
