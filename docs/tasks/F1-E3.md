# F1-E3: Engine — budget, warnings, and computeAll

**Goal:** the budget (`BudgetReport`), project warnings, and the aggregator function `computeAll` that the app calls in the Web Worker.

**May change:** `packages/engine/src/budget/**`, `packages/engine/src/warnings/**`, `packages/engine/src/compute.ts`, `packages/engine/src/index.ts` (exports only), `packages/engine/test/budget/**`, `packages/engine/test/compute/**`, `packages/engine/test/warnings/**`.
**Do not change:** `src/schema/**`, `src/model/**`, `src/framing/**`, `src/quantities/**`, `src/weight/**`, `packages/catalog/**`.

## API
```ts
export function computeBudget(q: QuantityReport, w: WeightReport, model: BuildingModel, project: Project, catalog: Catalog, today: string /* YYYY-MM-DD */): BudgetReport;
export function computeWarnings(ctx: { project; model; pieces; quantities; budget; catalog }): EngineWarning[];
export interface ComputeOptions { today?: string } // default: the price book date (deterministic)
export function computeAll(project: Project, catalog: Catalog, opts?: ComputeOptions): Results;
export function computeFromJson(json: unknown, catalog: Catalog, opts?: ComputeOptions): { ok: true; results: Results; project: Project } | { ok: false; issues: { path: string; message: string }[] };
```
`computeAll` = `buildModel` → `generatePieces` → `computeQuantities` → `computeWeight` → `computeBudget` → `computeWarnings`; `structure: null` and `terrain: null` for now (Phase 2/4 cards fill them in); `timingsMs` per stage (`model`, `framing`, `quantities`, `weight`, `budget`, `warnings`, `total`) using `performance.now()` (available in the browser and in Node). `engineVersion` = `ENGINE_VERSION`, `catalogVersion` = `catalog.version`.

## Budget
- Base: `getPriceBook(catalog, project.priceBookId)`. Price of each line = `project.priceOverrides[priceItemId]` ?? price book item (`overridden` indicates it). No price → `missing: true`, price 0, goes into `missingPrices`.
- `material` = purchaseQty × price; `materialMax` = purchaseQty × (priceMax ?? price).
- `stale`: price date more than `constants.priceStaleDays` days before `today` → `stalePrices`.
- Labor per stage (`book.labor`): base `built_area` → model.builtArea; `footprint_area`; `roof_area` → areas.roof; `wall_area` → exteriorWallsNet + interiorWallsNet; `radier_area`; `steel_kg` → steelKg; `material_pct` → % of the stage's material. `rateMax` for the maximum. Stages in `project.budget.diyStages` → labor 0 and `diy: true`. Labor is only charged for stages that have lines.
- Freight per stage = (Σ weightKg of the stage's lines / 1000) × freight.distanceKm × freight.pricePerTonKm.
- `byStage` in `STAGE_ORDER` order (from `@chalecad/catalog`), only stages with a value; `subtotal` = material + labor + freight; `contingency` = subtotal × contingencyPct/100; `total` = subtotal + contingency; `totalMax` analogous with the maximums; `perM2` = total / builtArea.
- `schedule`: if `durationsWeeks` exists, stages run in sequence in `STAGE_ORDER` order; each stage spreads its total (with proportional contingency) equally over its weeks; weeks numbered from 1.

## Warnings (`code`, `severity`, pt-BR `message`, `refs` with IDs to highlight in 3D)
- `opening.invalid` (error): opening with `valid: false` (nonexistent host, incompatible type, or outside the wall).
- `opening.modulation` (info): opening whose edges, shifted by up to 10 cm, would align with the stud modulation and save studs: message with the suggestion ("mover 7 cm para a direita economiza 1 montante" (moving 7 cm to the right saves 1 stud)).
- `steel.index` (warn): steelKgPerM2 outside `constants.steelIndexRange`.
- `price.missing` (warn) and `price.stale` (info), with a count.
- `stair.riser` (warn) if riser > `stairs.maxRiser`; `stair.blondel` (info) outside [blondelMin, blondelMax].
- `mezzanine.headroom` (warn): clear height under the roof at the center of the mezzanine < 2.0 m, or under the mezzanine < 2.2 m.
- `typology.partial` (info): typology without a roof structure generator yet (roof pieces missing).
- `extras.ignored` (info): extras present that the engine does not yet calculate; `site.sloped` (info) likewise for sloped terrain.
- Sort by severity (error, warn, info).

## Acceptance tests
- Budget of hand-built synthetic quantities (3 lines with known prices): material, labor, freight, contingency, and total checked by hand.
- `priceOverrides` replaces the price and marks `overridden`; nonexistent item → `missing`.
- `diyStages: ['structure']` zeroes the structure labor.
- Price dated 2026-01-01 with today 2026-11-07 → stale.
- `schedule` with durations {foundation: 2, structure: 3} → 5 weeks, sum = total of the two stages.
- `computeAll` of the 6.5 x 8.5 fixture: runs (it may depend on `generatePieces`/`computeQuantities` existing on your branch: if they do not exist yet when you start, implement the budget and warnings with unit tests and leave the integration test with a documented `test.skipIf`; the orchestrator enables it at integration).
- `computeFromJson` with invalid JSON returns issues.
- `computeAll` result is serializable and deterministic (two runs deep-equal, except `timingsMs`).
