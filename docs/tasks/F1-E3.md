# F1-E3: Motor — orçamento, alertas e computeAll

**Objetivo:** orçamento (`BudgetReport`), alertas do projeto e a função agregadora `computeAll` que o app chama no Web Worker.

**Pode alterar:** `packages/engine/src/budget/**`, `packages/engine/src/warnings/**`, `packages/engine/src/compute.ts`, `packages/engine/src/index.ts` (só exports), `packages/engine/test/budget/**`, `packages/engine/test/compute/**`, `packages/engine/test/warnings/**`.
**Não altere:** `src/schema/**`, `src/model/**`, `src/framing/**`, `src/quantities/**`, `src/weight/**`, `packages/catalog/**`.

## API
```ts
export function computeBudget(q: QuantityReport, w: WeightReport, model: BuildingModel, project: Project, catalog: Catalog, today: string /* YYYY-MM-DD */): BudgetReport;
export function computeWarnings(ctx: { project; model; pieces; quantities; budget; catalog }): EngineWarning[];
export interface ComputeOptions { today?: string } // default: data da base de preços (determinístico)
export function computeAll(project: Project, catalog: Catalog, opts?: ComputeOptions): Results;
export function computeFromJson(json: unknown, catalog: Catalog, opts?: ComputeOptions): { ok: true; results: Results; project: Project } | { ok: false; issues: { path: string; message: string }[] };
```
`computeAll` = `buildModel` → `generatePieces` → `computeQuantities` → `computeWeight` → `computeBudget` → `computeWarnings`; `structure: null` e `terrain: null` por enquanto (cards da Fase 2/4 preenchem); `timingsMs` por etapa (`model`, `framing`, `quantities`, `weight`, `budget`, `warnings`, `total`) usando `performance.now()` (disponível no browser e no Node). `engineVersion` = `ENGINE_VERSION`, `catalogVersion` = `catalog.version`.

## Orçamento
- Base: `getPriceBook(catalog, project.priceBookId)`. Preço de cada linha = `project.priceOverrides[priceItemId]` ?? item da base (`overridden` indica). Sem preço → `missing: true`, preço 0, entra em `missingPrices`.
- `material` = purchaseQty × price; `materialMax` = purchaseQty × (priceMax ?? price).
- `stale`: data do preço com mais de `constants.priceStaleDays` dias antes de `today` → `stalePrices`.
- Mão de obra por etapa (`book.labor`): base `built_area` → model.builtArea; `footprint_area`; `roof_area` → areas.roof; `wall_area` → exteriorWallsNet + interiorWallsNet; `radier_area`; `steel_kg` → steelKg; `material_pct` → % do material da etapa. `rateMax` para o máximo. Etapas em `project.budget.diyStages` → mão de obra 0 e `diy: true`. Só cobre mão de obra de etapas que têm linhas.
- Frete por etapa = (Σ weightKg das linhas da etapa / 1000) × freight.distanceKm × freight.pricePerTonKm.
- `byStage` na ordem `STAGE_ORDER` (de `@chalecad/catalog`), só etapas com valor; `subtotal` = material + labor + freight; `contingency` = subtotal × contingencyPct/100; `total` = subtotal + contingency; `totalMax` análogo com máximos; `perM2` = total / builtArea.
- `schedule`: se houver `durationsWeeks`, etapas em sequência na ordem `STAGE_ORDER`; cada etapa distribui seu total (com contingência proporcional) igualmente nas suas semanas; semanas numeradas a partir de 1.

## Alertas (`code`, `severity`, `message` pt-BR, `refs` com IDs para destacar no 3D)
- `opening.invalid` (error): abertura com `valid: false` (host inexistente, tipo incompatível ou fora da parede).
- `opening.modulation` (info): abertura cujas bordas, deslocadas em até 10 cm, alinhariam com a modulação dos montantes e economizariam montantes: mensagem com a sugestão ("mover 7 cm para a direita economiza 1 montante").
- `steel.index` (warn): steelKgPerM2 fora de `constants.steelIndexRange`.
- `price.missing` (warn) e `price.stale` (info), com contagem.
- `stair.riser` (warn) se riser > `stairs.maxRiser`; `stair.blondel` (info) fora de [blondelMin, blondelMax].
- `mezzanine.headroom` (warn): altura livre sob o telhado no centro do mezanino < 2,0 m, ou sob o mezanino < 2,2 m.
- `typology.partial` (info): tipologia sem gerador de estrutura de cobertura ainda (peças de cobertura ausentes).
- `extras.ignored` (info): extras presentes que o motor ainda não calcula; `site.sloped` (info) idem para terreno inclinado.
- Ordene por severidade (error, warn, info).

## Testes de aceite
- Orçamento de quantidades sintéticas montadas à mão (3 linhas com preços conhecidos): material, labor, frete, contingência e total conferidos à mão.
- `priceOverrides` substitui o preço e marca `overridden`; item inexistente → `missing`.
- `diyStages: ['structure']` zera a mão de obra da estrutura.
- Preço de 2026-01-01 com today 2026-11-07 → stale.
- `schedule` com durações {foundation: 2, structure: 3} → 5 semanas, soma = total das duas etapas.
- `computeAll` do fixture 6,5 x 8,5: roda (pode depender de `generatePieces`/`computeQuantities` existirem no seu branch: se ainda não existirem quando você começar, implemente o orçamento e os alertas com testes unitários e deixe o teste de integração com `test.skipIf` documentado; o orquestrador habilita na integração).
- `computeFromJson` com JSON inválido devolve issues.
- Resultado de `computeAll` serializável e determinístico (duas execuções deep-equal, exceto `timingsMs`).
