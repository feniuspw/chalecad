# F1-E1: Engine — LSF (light steel frame) piece generator (framing)

**Goal:** generate all steel pieces (`Piece[]`, see `packages/engine/src/schema/results.ts`) from the `BuildingModel` (from `buildModel`) + project + catalog.

**May change:** `packages/engine/src/framing/**`, `packages/engine/src/index.ts` (exports only), `packages/engine/test/framing/**`, `packages/engine/test/helpers/**` (may add).
**Do not change:** `packages/engine/src/schema/**`, `packages/catalog/**`, `src/model/**` (bug in buildModel → describe it in the open questions).

## API
```ts
export function generatePieces(model: BuildingModel, project: Project, catalog: Catalog): Piece[];
```
Constants from `catalog.constants` (lsf.*, roof.*). No hard-coded technical numbers other than geometric tolerances. In tests use `getCatalog()` from `@chalecad/catalog` (the real catalog).

Deterministic IDs `${hostId}:${role}:${n}`. Global coordinates (z up). `webNormal` per the comment on the `Piece` type.

## Walls (each `HostWall`)
Local: u along from→to, v up from baseZ.
- **Bottom track** (`track_bottom`, `system.profiles.wallTrack`): u=0..length, interrupted at door/sliding-door openings.
- **Top track** (`track_top`): follows the top edges of the `outline` (rectangle: 1 piece; gable end: one per sloped edge). Walls longer than `lsf.maxPanelLength` become several panels (split tracks and a double stud at the split).
- **Studs** (`stud`, `wallStud`) at u = 0, s, 2s… (s = `system.studSpacing`) and at the end; height = top of the outline at that u. Exterior walls: an extra `stud_corner` at each end (double stud). Where an interior wall meets a wall: an additional stud on the receiving wall, at the meeting position.
- **Valid openings** of the host: remove studs from the modulation inside [u0, u1]; `king` (full height) and `jack` (base to v1) on each side; `header` = 2 Ue pieces with the stud web (box header), length = span + 2·lsf.headerBearing, at v1; `cripple` above the header at the modulation positions up to the top; window: `sill` (track) at v0 and `cripple` below.
- **Blocking** (`blocking`, wallTrack profile): rows = floor(average height / lsf.blockingSpacing), one piece per bay.
- **Straps** (`strap`, `Fita70x0.95`): horizontal bracing strap at mid-height on every wall; if `system.bracing = 'strap'`, X in each exterior wall panel with no openings and ≥ 1.2 m.
- Wall with `assemblyId = 'gable_glazed'`: only tracks + studs every 1.2 m (glazing frame).

## Mezzanine (each `SlabModel` of kind `mezzanine`)
- Span direction: the direction (x or y of the polygon bbox) in which the two opposite edges coincide (±5 cm) with exterior or `loadBearing` walls; if both, the one with the shorter span; if neither, the shorter one (the structural check will warn).
- `joist` (`system.profiles.joist`) every `studSpacing`, edge to edge (clipped by the polygon).
- `rim` (rim track: replace the joist's `Ue` prefix with `U`, e.g., `U200x40x1.25`) on the perimeter.
- `blocking` at mid-span when span > 3 m.

## Roof
- **gable_mezzanine**: `rafter` (`system.profiles.rafter`) every `roof.rafterSpacing` along the ridge, on each roof plane, from eave to ridge (length = vLength); `ridge` (U with the rafter web) at the ridge; `collar_tie` (rafter profile) every 2 pairs, at 2/3 of the rise, only where there is no mezzanine under that pair; `purlin` (`system.profiles.purlin`) on each roof plane every `roof.purlinSpacing` along the plane (includes eave and ridge), length = uLength.
- **a_frame**: `rafter` on each roof plane, from the base (z = kneeWallHeight) to the ridge; `collar_tie` at 2/3 of the height on each pair, except where there is a mezzanine; `ridge`; `purlin` as above.
- Other typologies: export `framers: Partial<Record<TypologyKind, RoofFramer>>` and, if there is no framer, simply do not generate roof pieces (no error).

## Stairs
- `stair_stringer` (2 per flight, joist profile): length = hypotenuse of the flight; L = 2 flights; ship's ladder = 2 lateral `stud`s.

## Acceptance tests (`test/framing/`)
- 6.5 x 8.5 fixture: > 400 pieces; no length ≤ 0 or NaN; every profileId exists in the catalog; unique IDs.
- `ext-left` (8.5 m, s = 0.6, one 1.2 m window): stud count checked by hand (document the calculation in the test).
- A door interrupts the bottom track of `ext-front` (≥ 2 track_bottom pieces).
- Gable end `ext-front`: stud at x ≈ 3.25 has height ≈ ridgeHeight (±2 cm).
- Mezzanine: joists in the x direction (span 6.5); quantity documented.
- Rafters: length ≈ (3.25 + 0.6)/cos35° (±1 cm).
- `bracing: 'strap'` generates X straps; `osb` only the horizontal one.
- `studSpacing 0.4` generates more studs than 0.6.
- Σ(length × massPerM)/builtArea between 15 and 35 kg/m² (print the value with `console.info`).
- A-frame: rafters reach z = 0 at x = 0 and x = w.
- `generatePieces` of the fixture < 30 ms (average of 20).
