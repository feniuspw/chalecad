# F8-W2: App — getting started (ready-made templates, guided tour, and shortcut help)

**Goal:** someone opening ChaléCAD for the first time understands what to do within 1 minute and starts from a good-looking template, already with rooms, finishes, and furniture. Existing users find the shortcuts easily.

**May change:**
- `apps/web/lib/project/presets/**` (new) and `apps/web/lib/project/templates.ts`, only to expose the ready-made templates.
- `apps/web/components/editor/NewProjectDialog.tsx`.
- `apps/web/components/onboarding/**` (new).
- `apps/web/components/editor/EditorShell.tsx`, only to mount the tour, the help button/shortcut, and the shortcuts overlay.
- `apps/web/components/projects/**`, for the empty state of the project list.
- `apps/web/app/page.tsx` (landing), only if linking the templates is needed.
- Tests alongside.

**Do not change:** `packages/**`, `lib/store/**`, `package.json`, `components/scene/**`, `components/results/**`, `components/editor/properties/**`, `lib/plan2d/**`, and `lib/pdf/**` (belonging to card F7-W1, in parallel).

## 1. Ready-made templates (`lib/project/presets/*.ts`)
- 5 complete, valid projects (they pass `Project.parse`), built with the editing functions that already exist (`createProject`, `addRoom`, `addFurniture`, `setFinish`, `addAnnex`…):
  1. **Compact A-frame 6 × 8:** mezzanine, integrated living room/kitchen, bathroom, glass facade, lambri (tongue-and-groove wood) ceiling lining, and furniture.
  2. **A-frame with side rooms**, like the CasaPinus one: annexes on both sides (bedroom and bathroom), living room, mezzanine, and furniture.
  3. **Gable chalet 6.5 × 8.5 with mezzanine:** 1 bedroom, bathroom, kitchen, living room, deck at the front, wood siding.
  4. **Gambrel cabin 6 × 7:** loft.
  5. **L-shaped 2-bedroom house:** rooms and furniture.
- Each template has a name, short description, area, and estimated cost. The cost is computed with the engine in the tests and stored in a constant for display only. Update it if it changes and let the test warn when it diverges by more than 15%.
- Test:
  - all templates validate;
  - `computeAll` runs with no `error` in `warnings`;
  - closed rooms (`polygon` ≠ null);
  - furniture with no `furniture.collision` or `furniture.wall`.

## 2. New project (`NewProjectDialog.tsx`)
- Two tabs: **Modelos prontos** (Ready-made templates) (default) and **Do zero** (From scratch) (the current wizard).
- The template cards have:
  - thumbnail: a simple SVG of the facade or floor plan generated from the geometry, with no external images; reuse `lib/plan2d/elevation.ts` or the floor plan, read-only;
  - name, area, bedrooms, and cost.
- Choosing a template creates the project (with an editable name) and opens the editor.
- In the empty project list (`components/projects`): a "Comece por um modelo pronto" (Start from a ready-made template) call to action, with 3 cards.

## 3. Guided tour (`components/onboarding/Tour.tsx`)
- On the first opening of the editor (flag in `localStorage` inside try/catch; without storage, it does not show), a 6-step tour with balloons anchored to the elements (via `data-tour="..."`). Add the attributes where needed, only in the allowed files; the rest you anchor with an existing selector:
  1. properties panel ("mude medidas e veja tudo recalcular");
  2. toolbar (wall, opening, room, furniture);
  3. view modes (Finished, Structure, Exploded, Presentation);
  4. results panel (cost, materials, warnings);
  5. "Ajustar às normas" (Adjust to codes) / Alertas (Warnings) tab;
  6. Export (PDF, CSV, DXF).
- "Pular" (Skip), "Anterior" (Previous), "Próximo" (Next), 1/6 indicator, `Esc` closes.
- In the help menu: "Refazer o tour" (Redo the tour).
- No new library: a popover positioned via `getBoundingClientRect`, with a highlight of the element (shadow/cutout).

## 4. Shortcuts (`components/onboarding/ShortcutsDialog.tsx`)
- `?` (Shift+/) opens a dialog with all the editor's shortcuts, grouped (Tools, Editing, View, Furniture, Presentation).
- Take the list from the real source: `EditorShell` registers the shortcuts. Extract a `SHORTCUTS` table into a shared file and use it in both places, so they do not diverge.
- A discreet "?" button in the corner of the top or bottom bar opens the same dialog, with the menu: Shortcuts, Redo the tour, About/ART notice.

## Acceptance tests
- Ready-made templates: validation, closed rooms, no collisions, consistent cost (±15%).
- `SHORTCUTS`: no repeated keys in the same context.
- The tour skips steps whose element does not exist (test of the pure function that filters the steps).
- `pnpm --filter @chalecad/web typecheck`, `lint`, `test`, and `build` green (separately).
- In the return: how to verify and what was left out.
